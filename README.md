# beyond-one-gaussian-heteroskedastic-mlps-mixture-density-networks-and-mc-dropout-from-scratch
Most regression models assume the output is one Gaussian with one noise level. This project works through chapter 13 of Murphy's Probabilistic Machine Learning to find out what that assumption costs, on two problems where it fails and whose true densities you can compute, so every model is scored against the truth.
